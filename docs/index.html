Retina fullscreen fix

Dungeon Keeper Gold on modern Macs

Keep the original GOG game and launcher, but replace its 2014 DOSBox renderer with modern DOSBox Staging—for single-player and multiplayer.

What this fixes

The GOG wrapper can create a full-screen Retina surface while drawing the game as a small rectangle in the centre. This patch makes both single-player and multiplayer scale across the complete display, and closes the GOG launcher when the game starts.

Install

  1. Install your legitimate GOG copy of Dungeon Keeper Gold™ in Applications.
  2. Install Homebrew, then DOSBox Staging:
    brew install dosbox-staging
  3. Download this repository and run:
    chmod +x install.sh
./install.sh
  4. Open Dungeon Keeper Gold™ normally and choose Singleplayer or Multiplayer.

Multiplayer

Host: choose Start Network Host Game. DOSBox Staging opens an IPX-over-UDP server on port 19900.

Client: choose Start Network Client Game and enter the host address followed by the port, for example:

192.168.1.20 19900

For internet play, forward UDP port 19900 to the host Mac, or connect both computers through Tailscale or ZeroTier and use the host's VPN address.

Display preference

The default profile stretches the game to fill the display. For original 4:3 proportions, open files/dosboxDK_staging.conf, change aspect=stretch to aspect=on, then run the installer again.

Zoom on a MacBook

The original DOS game does not support mouse-wheel or two-finger trackpad zoom. Use the original Home/End controls through their MacBook equivalents:

Fn + Left Arrow   Zoom in
Fn + Right Arrow  Zoom out

Higher internal resolution

After entering an actual dungeon level, press Option + R (DOS Alt + R) to switch from the original low-resolution mode to its high-resolution mode. Fullscreen scaling and internal rendering resolution are separate: this patch fills the Retina panel, while Option + R makes the game itself draw more detail.

The original executable cannot render at arbitrary HD or Retina resolutions. Use KeeperFX if you need a truly modern internal resolution.

No game files are included. Your GOG CD image, audio, saves and language selection remain untouched.

Undo

./uninstall.sh

Full details and custom application paths are documented in README.md in the repository.
